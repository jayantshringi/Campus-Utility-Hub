# Campus Utility Hub

**Campus Utility Hub** is a lightweight, responsive, and interactive suite of web tools designed to make college life and academic tasks easier to manage. Built as a CS-201 Web Technologies Lab Project, it features a clean, dynamic, and humanized design system with real-time UI customization.

---

## 🚀 Key Modules & Features

### 1. 🏠 Home Dashboard
- Overview of active modules.
- Quick launch buttons with hover micro-animations.

### 2. 📋 Smart Attendance Tracker
- Add students and log lectures (Present, Absent, Late).
- Real-time attendance percentage calculator.
- Built-in warning indicators if attendance falls below the crucial **75% threshold**.

### 3. 🎓 SGPA / CGPA Calculator
- Dynamic subject entry form.
- Direct letter grade to point mapping (O, A+, A, etc.).
- Auto-calculates GPA based on course credits.

### 4. 🔢 Binary & Number Converter
- Dynamic conversion between Base 2 (Binary), Base 10 (Decimal), Base 8 (Octal), and Base 16 (Hexadecimal).
- Pure JavaScript division and multiplication algorithms.

### 5. 🔑 Password Strength Analyzer
- Live password entropy check with color-coded width meters.
- Multi-rule verification checklist (casing, numbers, symbols, length).
- Password visibility toggler.

### 6. ❓ Dynamic Trivia Quiz
- Interactive campus and programming trivia loaded dynamically.
- Interactive question-by-question progress bar.
- Detailed visual breakdown of correct vs. skipped answers.

### 7. 💸 Shared Expense Splitter
- Shared dorm ledger using Indian Rupees (`₹`).
- greedy transaction path calculation to resolve debts ("who owes how much to whom").
- Add/delete participants and expenses dynamically.

### 8. 🎨 Live CSS Theme Generator
- Customize the primary accent color, font size, border radius, and spacing in real-time.
- Responsive layout resets instantly to default parameters.

### 9. ⌨️ Typing Speed Tester
- WPM (Words per minute), mistakes, and accuracy tracking.
- Interactive 60-second typing timer block.
- Refreshable paragraph selections.

---

## 🛠️ Technology Stack

- **Markup**: Semantic HTML5.
- **Styling**: Vanilla CSS3 (dynamic variables, custom glassmorphism components, and color-mixing logic).
- **Interactivity**: Pure Vanilla JavaScript (ES6+).
- **Typography**: Google Font Integration (`Plus Jakarta Sans`).

## 📦 How to Run Locally

Since the project is built on standard web technologies, there are no heavy installations required:

1. Clone this repository:
   ```bash
   git clone https://github.com/jayantshringi/Campus-Utility-Hub.git
   ```
2. Navigate into the folder:
   ```bash
   cd "CAMPUS UTILITY HUB"
   ```
3. Open `index.html` in any web browser.
